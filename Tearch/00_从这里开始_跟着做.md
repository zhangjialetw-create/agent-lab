# 从 Python 基础走到可训练 Agent Harness：跟着做

更新：2026-10-20。对象：了解 Python 基础概念、前六天主要照着复制、希望亲手搭建 Agent 的你。

这套内容直接替代“先读完课程再动手”的安排。必做部分的知识、代码和练习都在这里；外部链接只用于核对和深入。不用购买视频课，不需要付费 API。

## 终点是什么

你会做出一个本地“学习助手”：读学习记录、查自己的 Markdown 知识库、加载一个 Skill、按确认的偏好回答、记录每步日志，用固定题目评测。然后训练一个决定使用哪种工具的小模型，保存参数并接回 Harness。最后选做一个真正更新语言模型 LoRA 参数的实验。

一句话解释：**模型决定下一步，Harness 管理下一步能不能做、怎么做、做完留下什么证据。**

本项目采用受约束的单 Agent：一次查资料或统计，然后回答。这个边界适合当前的小模型，也便于看懂每次错误。长任务、多工具链、多 Agent 是结业后的扩展。

## 怎么学

1. 一次只做一节，建议 30—60 分钟；较长的代码讲解可以拆成两次。
2. 先读“目标”，再执行。代码块标为 `powershell` 的放终端；`python` 的写进指定 `.py` 文件；JSON/Markdown 放各自文件。
3. 每次只改一个地方，按 Ctrl+S，再运行。
4. 先预测输出，再对照实际结果。不同就停下来定位。
5. 做完小练习，能解释验收问题，再继续。按进度走，不要求十天赶完。
6. 卡住时发“第几阶段第几节 + 输入的命令 + 完整报错 + 你以为会出现什么”。可以继续在这个聊天中逐节学。

普通课时合计约 25—40 小时，按你的反馈可以更慢。LoRA 的下载和训练时间另算；本地模型首次装载也可能明显慢于后续调用。

## 哪些概念先分清

| 名称 | 回答的问题 | 本项目例子 |
|---|---|---|
| 模型 | 根据输入选择/生成什么 | 本机 DeepSeek；训练后的路由器 |
| 工具 | 具体如何执行操作 | 读取 JSON，计算总分钟 |
| 知识库 | 有什么资料可查 | Python 环境、Git 的笔记 |
| Skill | 某类任务应该怎么做 | 先查证据，再回答并引用 |
| 记忆 | 下次仍需保留什么 | 你确认的表达偏好 |
| Harness | 如何把以上部件可靠地组织起来 | 协议、校验、工具调用、预算、日志 |
| 评测 | 比原来好了吗 | 同一批题、同一预算的前后对比 |
| 训练 | 哪些参数通过数据发生了变化 | router.json 的权重；可选 LoRA adapter |

当前主线用了现代 Agent 常见的结构化输出、证据检索、按需加载 Skill、状态约束、可替换模型和可复现评测。选这些组件的依据与扩展路线见阶段 07；不以“模型最新”代替实际可靠性。
