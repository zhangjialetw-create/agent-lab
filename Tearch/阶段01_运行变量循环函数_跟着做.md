## 第 1 节：建立专用练习文件夹和环境

打开 VS Code 的“终端 → 新建终端”，确认使用 PowerShell。下面逐条执行，上一条成功再输下一条。

```powershell
Set-Location -LiteralPath 'D:\Society\1\Harness\Agent学习教程_10天\实验操作区'
New-Item -ItemType Directory -Path agent-lab
Set-Location -LiteralPath '.\agent-lab'
```

`New-Item` 创建东西，`-ItemType Directory` 表示创建文件夹，`-Path` 是名字。如果已经存在这个文件夹，跳过创建，进入它即可；不要清空已有内容。

接着借用已确认能运行的 Python 创建新环境：

```powershell
& 'D:\Society\1\Harness\Agent学习教程_10天\实验操作区\study-log\.venv\Scripts\python.exe' -m venv .venv
.\.venv\Scripts\python.exe --version
```

预期最后一行：`Python 3.12.2`。创建环境时暂时没有输出是正常现象。

逐段理解：

- `&`：PowerShell 的调用符号，让引号中的程序路径真正执行。
- 那段长路径：以前项目里能运行的 Python。
- `-m venv`：让这个 Python 运行自带的环境创建模块。
- 最后的 `.venv`：新环境的文件夹名字，创建在当前 `agent-lab` 中。
- 新环境中的包独立管理；它仍依赖电脑上的基础 Python，不是可任意复制到另一台电脑的完整系统。

通过 VS Code“文件 → 打开文件夹”打开 `agent-lab`。再开终端。如果忘了终端在哪儿，运行 `Get-Location`。下面所有阶段默认都在这个项目根目录执行。

```powershell
New-Item -ItemType Directory -Path basics
```

在 VS Code 左侧 `basics` 上右键新建文件，命名 `01_values.py`。创建文件是编辑器操作，下面的代码放进文件，**不要把代码围栏的三个反引号复制进去**。

## 第 2 节：变量不是输出，print 才显示结果

文件 `basics/01_values.py`，完整内容：

```python
name = "Python 学习者"
minutes = 25
extra = 10
total = minutes + extra
print(f"{name}今天学习了 {total} 分钟")
```

保存后，在项目根目录的终端执行：

```powershell
.\.venv\Scripts\python.exe basics/01_values.py
```

预期：`Python 学习者今天学习了 35 分钟`。

逐行读：

| 行 | 含义 |
|---|---|
| `name = ...` | 把一段文字赋给名字 `name` |
| `minutes = 25` | 把整数 25 赋给 `minutes` |
| `extra = 10` | 保存另一个数 |
| `total = minutes + extra` | 先算右边的 25+10，再把结果存到 total |
| `print(f"...")` | 替换花括号里的变量，然后显示整句话 |

小练习：把 `minutes` 改成 40。先说出预期，再保存、运行。应显示 50 分钟。

再试一次：把 `minutes` 写成 `"40"`，运行会发生文字和整数不能相加的错误。双引号改变了类型。读最后一行错误后，恢复为数字 `40`。

验收：不用看答案，说出 `25` 与 `"25"` 的区别。

## 第 3 节：用列表放多条记录，用字典给每条记录起字段名

新建 `basics/02_records.py`：

```python
records = [
    {"topic": "Python", "minutes": 25},
    {"topic": "终端", "minutes": 35},
    {"topic": "复习", "minutes": 15},
]
total = 0
for record in records:
    total = total + record["minutes"]
    print(record["topic"], record["minutes"])
print("总分钟：", total)
```

```powershell
.\.venv\Scripts\python.exe basics/02_records.py
```

预期依次显示 Python 25、终端 35、复习 15，最后总分钟 75。

这次有三个新概念：

1. 外层 `[...]` 是列表，按顺序放三条记录。
2. 每条 `{...}` 是字典；`"topic"` 与 `"minutes"` 是键，相应的文字和数字是值。
3. `for record in records:` 每次从列表拿一条记录，让 `record` 临时代表它；下面缩进的两行每条记录各执行一次。

跟踪 `total`：初始 0 → 第一轮 25 → 第二轮 60 → 第三轮 75。循环之后的最后一个 `print` 没有缩进，只执行一次。

`record["minutes"]` 意思是“拿当前这一条记录的 minutes 值”，不是“拿整张列表”。

小练习：在列表最后增加 `{"topic": "Git", "minutes": 20}`，注意前一项后面需要逗号。预期总分钟变为 95。完成后可以恢复原数据，方便后面的示例数字一致。

卡点：`IndentationError` 检查每层用 4 个空格；`KeyError` 检查键有没有把 `minutes` 拼错；`SyntaxError` 检查逗号、引号、括号是否成对。

验收：能解释为什么循环里的 `print` 出现三次，最后的 `print` 只出现一次。

## 第 4 节：函数把“输入 → 处理 → 输出”包起来

新建 `basics/03_functions.py`：

```python
def summarize(records):
    count = len(records)
    total = 0
    for record in records:
        total = total + record["minutes"]
    if count == 0:
        average = 0.0
    else:
        average = total / count
    return {"count": count, "total": total, "average": average}


if __name__ == "__main__":
    result = summarize([{"topic": "Python", "minutes": 25}])
    print(result)
    print(summarize([]))
```

```powershell
.\.venv\Scripts\python.exe basics/03_functions.py
```

预期两个字典：第一个 `count=1,total=25,average=25.0`；第二个 `count=0,total=0,average=0.0`。

按执行顺序理解：

1. `def summarize(records):` 定义函数；此时只是登记做法，还没有统计任何记录。
2. `summarize([...])` 才真正调用它，把列表传给参数 `records`。
3. `len(records)` 数记录条数；循环计算 total。
4. `if count == 0` 判断是否为空；`==` 比较相等，和赋值 `=` 不同。
5. 空列表单独处理，可以避免用 0 作除数。
6. `return {...}` 把结果交还调用者，`result` 接住它。
7. `print(result)` 才把返回值显示出来。返回与显示是两件事。

`if __name__ == "__main__":` 的作用先记成：直接运行这个文件时，执行下面的演示；以后其他文件导入函数时，不自动执行演示。下一阶段会实际体验。

小练习：把演示输入改成两条记录，分钟为 20 和 40。运行前写出预测：count 2、total 60、average 30.0。

结业门槛：能自己添加第三条记录，能解释空列表为什么不再报错，能说出函数的输入和返回值。做不到就继续改这个小例子，先不增加新工具。
