## 真实模型四题的结果与解释

最终代码的一次四题自动检查为 **2/4**。原始答案保存在 [eval-ollama.json](参考代码/artifacts/eval-ollama.json)，每条包含相应日志路径。

| 问题 | 自动结果 | 人工阅读 |
|---|---|---|
| 统计学习总分钟 | 通过 | 75 分钟，来源正确 |
| 如何创建虚拟环境 | 未通过 | 模型先选错统计工具，又生成错误命令与不存在的引用；框架拒绝最终回答 |
| Git 如何保存版本 | 通过 | 虽包含 commit 和正确来源，但把 git status 说成查看历史，答案仍有事实错误 |
| 量子海豚XYZ | 未通过 | 回答“无相关资料”，语义上正确；自动检查只匹配“未找到”，误判失败 |

这组结果同时展示三件事：小模型可能选错工具；关键词检查可能放过错误；严格措辞检查也可能错杀正确答案。教程保留原始结果供学习，没有把它改写成全部成功。此四题不足以估计实际总体成功率。

要稳定观察知识库流程，先用 mock 或训练后的路由模式；要研究语言模型表现，再使用 ollama 并核对具体答案。结业时应增加人工标注、同义拒答判断和事实一致性检查。
